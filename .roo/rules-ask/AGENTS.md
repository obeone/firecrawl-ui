# Ask-mode Rules (Non-Obvious Only)

- There is no generated API client: `src/services/firecrawl.ts` is a hand-written v2 adapter. Use the online v2 API reference (https://docs.firecrawl.dev/api-reference/v2-introduction) as the source of truth for payloads.
- API configuration UI lives in `src/views/ApiConfigView.vue`; useful for examples.
